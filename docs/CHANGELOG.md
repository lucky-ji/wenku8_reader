# 更新日志

## 1.0.3 · 2026-11-12

- 新增本章进度拖动与百分比预览，松手后跳转，支持滚动和翻页阅读。
- 新增独立章内查找页面，支持前后循环查找、正文预览和跳转阅读，未匹配时保留位置。
- 阅读页增加查找、书签和外观快捷入口，书签页支持直接添加当前位置。
- 桌面端增加 Ctrl+F 章内查找、Ctrl+D 添加书签快捷键。

- 阅读底部统一上一章、目录、下一章的对齐与宽度，阅读进度单独展示。
- 移动端按用途区分图标导航、成组工具栏、轻量胶囊和分组操作，保留触控区域、按压反馈和禁用区分。
- 桌面端保留按钮操作，统一阅读工具与主题配色层次。
- 整理阅读设置、目录、下载任务和关于页面的分组、间距与信息层级。

## 1.0.2 · 2026-11-10

- 分离下载缓存与下载到本地，支持选择并记住保存目录。
- 支持将小说保存为 UTF-8 文本、离线 HTML 与可选插图，已有文件不会被覆盖。
- 下载使用独立会话后台排队，可查看进度、暂停与继续，完成后显示自动消失的浮动提示。
- 实时保存章节和图片断点，重新打开并验证原账号后可恢复未完成任务。
- 增加行距、段间距和页边留白设置，调整后保留阅读位置。
- 改善移动端页面切换、设置返回与阅读交互，减少重复排版和缓存读取卡顿。
- 改进发现页榜单兼容及网络失败重试，保留已有内容与下载进度。
- 在应用内增加 GitHub 开源项目和意见反馈入口。

## 1.0.1 · 2026-11-06

- 修复移动端章节目录快速滑动时偶发反向惯性，改善拖动跟手性。
- 同步修正书架、搜索、正文与设置等共用触控区域的末端方向判断。
- 修复少量搜索结果在滚动条临界高度反复重排、闪烁的问题，并核查桌面卡片布局。
- 登录网页加载失败时提示检查网络及系统应用联网权限，正常加载时隐藏。
- 修复首次网页登录返回后的主界面解锁与焦点恢复流程。
- 精简小说卡片，移除重复的查看入口和单一书源占位文字。
- 调整 Android 登录返回流程，重建界面绘制资源并恢复画面刷新。

## 1.0.0 · 2026-11-05

轻小说文库首个正式版本。

- SDK、阅读界面与平台登录适配独立分层。
- 支持账号登录、会话保存、书架、小说发现与搜索、详情与章节目录。
- 支持正文与插图、滚动与翻页阅读，Android 音量键翻页。
- 支持下载与离线阅读、阅读历史、逐书阅读位置与书签。
- 提供明亮、暗色、护眼外观，以及移动端触控、下拉刷新和独立阅读目录。
- 提供封面缓存、失败重试、网络状态与加载反馈。
- 优化按钮交互，移除桌面端多余的焦点边框。
