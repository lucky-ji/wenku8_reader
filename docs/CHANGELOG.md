# 更新日志

## 1.0.1 · 2026-11-06

- 修复移动端章节目录快速滑动时偶发反向惯性，改善拖动跟手性。
- 同步修正书架、搜索、正文与设置等共用触控区域的末端方向判断。
- 修复少量搜索结果在滚动条临界高度反复重排、闪烁的问题，并核查桌面卡片布局。
- 登录网页加载失败时提示检查网络及系统应用联网权限，正常加载时隐藏。
- 修复首次网页登录返回后的主界面解锁与焦点恢复流程。
- 精简小说卡片，移除重复的查看入口和单一书源占位文字。
- 调整 Android 登录返回流程，重建界面绘制资源并恢复画面刷新。

## 1.0.0 · 2026-11-05

轻小说文库首个正式版本。

- SDK、阅读界面与平台登录适配独立分层。
- 支持账号登录、会话保存、书架、小说发现与搜索、详情与章节目录。
- 支持正文与插图、滚动与翻页阅读，Android 音量键翻页。
- 支持下载与离线阅读、阅读历史、逐书阅读位置与书签。
- 提供明亮、暗色、护眼外观，以及移动端触控、下拉刷新和独立阅读目录。
- 提供封面缓存、失败重试、网络状态与加载反馈。
- 优化按钮交互，移除桌面端多余的焦点边框。
