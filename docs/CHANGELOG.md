# 更新日志

## 1.0.7 · 开发中

- 增加鸿蒙 ARM64 客户端。宽窗口的鸿蒙 PC 使用侧栏，手机、平板和窄窗口使用触控导航。
- 鸿蒙端支持 ArkWeb 登录、书架、最近更新、搜索、章节阅读、阅读位置、书签与下载缓存。
- 提供未签名 Release HAP 的构建和校验流程。

## 1.0.6 · 2026-11-25

- SDK 独立版本为 1.1.0，将连接失败重试、退避及时间预算统一交给 SDK，调用方可在初始化时覆盖默认策略。
- 移动书架的继续阅读卡片可关闭，并可在「我的」重新开启。从小说详情返回时保留搜索结果。
- 桌面正文使用紧凑的书名与章名栏，侧栏支持快捷键开关，目录与章内查找支持键盘操作。
- 桌面书库支持封面网格与紧凑列表，可用快捷键搜索和选书，从详情返回后恢复选中项和滚动位置。
- 小说详情展示上次阅读章节及进度，支持按卷名和章名筛选目录，宽窗和宽幅横屏使用双栏。
- 移动阅读区优化书名与章名、进度预览和底部工具布局，横屏保留查找、书签、外观与听书入口。
- 「最近更新」支持封面平铺、紧凑列表和连续滚动加载，从详情返回时保留已加载列表与滚动位置。
- 浏览卡片显示网站提供的作者和连载状态，长作者名省略时保留状态标签。
- 封面平铺使用四宫格图标，书架入口保留书本图标。
- 启动后直接进入客户端，后台验证已保存的会话。用户可从「我的」登录，离线也能打开已下载的缓存。

## 1.0.5 · 2026-11-18

- 阅读设置按预览、阅读方式、字体与排版分组，统一参数步进与三种主题的控件效果。
- 定时关闭支持 1–1440 分钟自定义时长，页内编辑并确认生效，重新打开不重置倒计时。
- 增加基于系统语音引擎的前台听书，支持暂停继续、停止与逐段切换。
- 支持音色、语速、音调、音量、跟读定位、自动切章和睡眠定时。
- 联网音色明确标记并默认禁止联网合成，需用户单独允许。
- Android 在耳机断开或音频焦点变化时暂停，应用进入后台自动暂停并保留阅读位置。
- 引擎不可用时提供真实说明及可用的系统语音设置入口。

## 1.0.4 · 2026-11-16

- 连续切章保持工具栏显隐状态，减少阅读中断。
- 累计滚轮增量、限制一次触控板手势翻页，忽略惯性误触。
- 增加可选阅读常亮，后台与退出阅读恢复系统行为。
- 读取 Android 系统栏、挖孔和手势安全区，避免重复添加边距。
- 桌面目录、查找与书签共用可收起侧栏，保持正文可操作。
- 增加系统字体、粗体及即时排版预览，桌面可选择舒适宽度或全宽。
- 搜索展示匹配序号与总数，突出显示匹配词并安全处理特殊字符。
- 移动书签支持单击直达与管理模式，删除后可在五秒内撤销。
- 增加重复查找、章节切换快捷键及帮助说明。

## 1.0.3 · 2026-11-12

- 新增本章进度拖动与百分比预览，松手后跳转，支持滚动和翻页阅读。
- 新增独立章内查找页面，支持前后循环查找、正文预览和跳转阅读，未匹配时保留位置。
- 阅读页增加查找、书签和外观快捷入口，书签页支持直接添加当前位置。
- 桌面端增加 Ctrl+F 章内查找、Ctrl+D 添加书签快捷键。

- 阅读底部统一上一章、目录、下一章的对齐与宽度，阅读进度单独展示。
- 移动端按用途区分图标导航、成组工具栏、轻量胶囊和分组操作，保留触控区域、按压反馈和禁用区分。
- 桌面端保留按钮操作，统一阅读工具与主题配色层次。
- 整理阅读设置、目录、下载任务和关于页面的分组、间距与信息层级。

## 1.0.2 · 2026-11-10

- 分离下载缓存与下载到本地，支持选择并记住保存目录。
- 支持将小说保存为 UTF-8 文本、离线 HTML 与可选插图，已有文件不会被覆盖。
- 下载使用独立会话后台排队，可查看进度、暂停与继续，完成后显示自动消失的浮动提示。
- 实时保存章节和图片断点，重新打开并验证原账号后可恢复未完成任务。
- 增加行距、段间距和页边留白设置，调整后保留阅读位置。
- 改善移动端页面切换、设置返回与阅读交互，减少重复排版和缓存读取卡顿。
- 改进发现页榜单兼容及网络失败重试，保留已有内容与下载进度。
- 在应用内增加 GitHub 开源项目和意见反馈入口。

- 精简小说卡片，移除重复的查看入口和单一书源占位文字。
- 调整 Android 登录返回流程，重建界面绘制资源并恢复画面刷新。

## 1.0.0 · 2026-11-05

轻小说文库首个正式版本。

- SDK、阅读界面与平台登录适配独立分层。
- 支持账号登录、会话保存、书架、小说发现与搜索、详情与章节目录。
- 支持正文与插图、滚动与翻页阅读，Android 音量键翻页。
- 支持下载与离线阅读、阅读历史、逐书阅读位置与书签。
- 提供明亮、暗色、护眼外观，以及移动端触控、下拉刷新和独立阅读目录。
- 提供封面缓存、失败重试、网络状态与加载反馈。
- 优化按钮交互，移除桌面端多余的焦点边框。
