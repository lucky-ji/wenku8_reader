# 阅读性能验收

滚动流畅性需要在目标设备上测量。桌面窄屏截图、合成输入测试及构建成功不代表 Android 高刷新率设备已经通过验收。

## 固定场景

- 同一章节分别使用纯文字、长章节及带插图内容；固定字号、行距、模式与窗口尺寸。
- 冷启动一次，重复相同滑动轨迹；区分首次排版、稳定滚动、图片到达和切章。
- 在 60／90／120 Hz 设备设置下分别记录；保存设备型号、Android 版本、实际刷新率和温度状态。
- 观察连续切章、打开目录和设置后返回、前后台恢复、横竖屏及大字体。

## 指标

记录帧时间的中位数、P95、P99、最长停顿、输入到首帧延迟，以及 CPU／内存峰值。按实际刷新周期统计错过呈现时机的帧；不能把平均 FPS 代替掉帧分布。

Qt 5 当前共用惯性滚动配置为 Fps60。应先区分输入采样、文档排版、栅格缓存和 Surface 呈现瓶颈，再评估高刷调度；不通过提高定时器频率掩盖同步工作。

Android 可使用 Perfetto 的 FrameTimeline、输入、调度及图形轨迹；Qt Surface 的帧不一定完整出现在常规 View 的 gfxinfo 中，需要与 SurfaceFlinger／FrameTimeline 对照。采集在本地完成，不包含账号、Cookie 或章节正文。

## 当前边界

自动化覆盖事件累计、惯性忽略、方向反转、状态恢复、重复切页及阅读锚点；真机的高刷表现、挖孔／手势安全区和登录返回仍需设备验收。尚无连接设备时不填写虚构的真机帧率数据。
