# 界面设计约定

## 阅读界面

- 顶部承担返回、当前章节和设置；移动端左右操作等宽，标题居中。
- 底部三个操作按上一章（翻页模式为上一页）、目录、下一章（下一页）等宽排列，保持同一基线。
- 本章进度拖动时仅预览百分比，松手后跳转；程序同步滑块不触发跳转，单页或正文未就绪时禁用。
- 常用查找、书签、外观在移动阅读页直接进入；横屏收起快捷排，可经设置进入，避免挤压正文。桌面支持 Ctrl+F 查找与 Ctrl+D 添加书签。
- 章内查找独立展示前后匹配、正文预览及跳转操作，未找到时保留阅读位置；从查找返回时使用匹配锚点。
- 章节与本章页数独立展示，避免进度文本改变按钮位置。卷首、卷尾及忙碌状态保留禁用反馈。
- 移动端返回、设置采用图标与文字导航；目录与翻页归入共同工具容器。次要操作按用途使用文字、轻量胶囊或分组行，避免全部去掉可点击边界；可触控范围至少 48 像素，按下显示短暂反馈，松开后不保留悬浮底色。
- 桌面保留按钮、SVG 图标、悬浮和禁用状态；触控布局切回桌面时恢复对应图标与配色。

## 其他页面

- 书架、发现、搜索、历史和已缓存小说共用卡片布局，保持滚动条出现前后的列宽稳定；长状态文本省略显示。
- 小说详情保留一个明确的阅读主操作，书架、下载与简介为次要操作；移动端使用两列规则网格及轻填充的次要操作胶囊。
- 章节目录是阅读内独立二级页面，支持当前章定位、搜索结果数量和无匹配反馈。
- 设置采用统一圆角容器，将标签、减少、数值和增加组织成参数行；外观和阅读模式保留可见的选中状态。
- 下载任务分开显示书名、类型与状态、进度及操作；下载目录说明与缓存说明分别展示。
- 账户、版本说明、更新日志和许可分组呈现；桌面完整许可使用组件列表和正文分栏。

## 验证范围

界面调整应检查 320、360 像素窄屏、移动横屏与常规桌面窗口，覆盖明亮、暗色、护眼三种主题。检查文字溢出、按钮对齐、触控区域、禁用和选中对比，并重复打开设置、目录及返回阅读，核对阅读锚点与页面释放。桌面模拟窄屏不能替代 Android 真机的触控和系统窗口验证。

## 交互参考

- [Legado（Jer-Chao 分支）](https://github.com/Jer-Chao/legado)：阅读工具分区、同类设置容器与有明确边界的参数控制。参考 `view_read_menu.xml` 与 `dialog_read_book_style.xml` 的布局组织，采用 Qt 自有实现。

- [Readest](https://github.com/readest/readest) 及其[阅读界面说明](https://readest.com/docs/reading)：按需显示工具栏，分离阅读操作与进度信息。
- [KOReader](https://github.com/koreader/koreader) 及其[用户指南](https://koreader.rocks/user_guide/)：独立目录、简洁状态栏及清晰的设置分组。

以上仅用于交互与布局研究，未复制代码、图标或其他资源。

## 1.0.4／1.0.5 连续阅读

- 连续切章沿用工具栏显隐，新书首次进入才展示入口；滚轮按阈值累计，触控板一次手势只翻一页。
- 阅读常亮只在阅读、前台并持有焦点时生效，进入登录、后台或退出阅读恢复系统行为；系统安全区与 Qt 已有避让取最大值。
- PC 的目录、查找与书签共用非模态侧栏，正文继续可操作；缩窄为触控界面时收起，换书不显示旧内容。
- 正文默认保持全宽，可选择舒适宽度；字体、粗体与排版预览独立保存，不重置阅读位置。
- 搜索显示命中序号及总数，预览先转义正文再标记匹配；超过一万处用“至少”说明，避免超长章节无界枚举。
- 移动书签默认点击直达，管理模式才选择删除；删除后提供五秒页内撤销，不使用可点击浮动提示或模态弹窗。
