# 听书

1.0.5 开发中的听书使用设备系统的文字转语音引擎。打开小说正文后从“听书”进入，支持播放、暂停、继续、停止，以及上一段和下一段。默认从当前阅读位置所在段落开始，自动保存的阅读记录继续使用原来的章节与文字锚点。

## 播放设置

- 可选择系统提供的音色，并调节语速、音调和应用内音量。实际可用音色取决于设备上已安装的引擎和语音数据，中文音色优先。
- 可开启跟随朗读定位、自动读下一章，或在本章结束时停止。睡眠定时到期后停止朗读。
- 当前仅支持前台朗读。应用进入后台或退出阅读时暂停；Android 失去音频焦点或耳机／音频设备断开时也暂停，返回后由用户继续。没有后台常驻服务、锁屏播放或通知播放器。

## 离线与联网音色

Android 音色显示“离线”“需联网”或“需下载语音”。引擎未提供网络信息的默认中文音色按可能联网处理。应用默认不允许联网合成；只有用户开启“允许所选系统音色联网合成”后，才可使用需联网的系统音色。此时文字可能由所选系统引擎发送给其服务提供方，应按该提供方的隐私与服务规则判断是否使用。

本项目没有内置在线 TTS 服务、API 密钥、语音模型下载或第三方云端 SDK，也不会为没有接入的服务展示可播放入口。离线音色由系统引擎在设备上合成；实际能力和处理方式以系统引擎说明为准。

## 系统准备

Windows 需安装可用的系统语音；macOS 使用系统语音；Linux 需 Qt Speech 插件、Speech Dispatcher 与对应语音数据。Android 需安装并启用文字转语音引擎及中文音色，界面会在系统能够处理对应设置入口时提供跳转。没有可用引擎、语音数据缺失或初始化失败时，会显示实际原因并保留阅读位置，不会伪装成播放成功。

## 设计与验证

逐段切分与定位由客户端控制，平台适配只接收当前待朗读的片段。每段使用独立播放编号；停止、切章及销毁后的旧回调不能推进新段落。SDK 仍为不依赖 Qt 的 C++ 库，不承担语音播放或 UI 状态。

交互与职责划分研究参考 [Legado](https://github.com/Jer-Chao/legado) 和 [Readest](https://github.com/readest/readest) 的公开功能组织，未复制其实现或资源。

设备验收应覆盖中文正常发声、引擎未安装／不可用、音色切换、网络许可关闭、逐段跳转、章节边界、睡眠定时、后台暂停，以及 Android 耳机断开和音频焦点变化。逻辑测试、编译和界面截图不能替代这些音频设备验证。
